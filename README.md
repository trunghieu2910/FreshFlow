# FreshFlow

FreshFlow là nền tảng đặt món cho cửa hàng nhỏ, được xây dựng để học tập và làm portfolio.

## MVP 12 tuần

- Spring Boot + PostgreSQL backend.
- React Web cho Merchant.
- Android Kotlin cho Customer.
- REST API, JWT/RBAC, JPA/Flyway và Docker Compose.
- Catalog, cart, checkout, order, inventory và testing.

Electron, driver workflow, Maps, Chat, push notification thật,
payment thật, Redis, Kafka, Kubernetes và cloud production thuộc phạm vi mở rộng sau MVP.
